## Demo states
The mockup has a demo-state picker (Meer → "Mockup · toestand", or `?demo=<state>` in the URL; `?scope=` sets the scope switch):

| State | Key | Shows |
|---|---|---|
| Normaal | `normaal` | The story above |
| Nog geen rekeningen | `leeg` | First run: no Enable Banking app, no accounts, welcome steps and empty states |
| Sync verouderd | `verouderd` | The last sync is 3 days old (warning) |
| Sync mislukt | `fout` | The bank does not answer (error), sidebar dot red |
| Alleen lezen | `lezen` | Partner is manager of the shared account and gave Bert Lezen: no edit controls there |
| Offline | `offline` | A banner on every page, saving disabled |
