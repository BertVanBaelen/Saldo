# Inloggen and Code

Analysis: 7, 12 (screen 1) · Design: to design · Concepts: [authentication](../concepts/authentication.md), [user-and-visibility](../concepts/user-and-visibility.md) · Phases: [0.1-6](../../plan/v0.1-mockup/06-missing-designs.md), [0.2-4](../../plan/v0.2-foundation/04-sign-in-users-mail.md)

## Content to design
- Sign-in: email and password. No "forgot password" link, no registration.
- Code: 8-digit email code (10 minutes, 5 attempts), resend with rate limit.
- First-admin setup from the one-time link in the add-on log.
- Accept an invitation and choose a password. Choose a new password from a reset link.
- Optional "Inloggen met Home Assistant".
