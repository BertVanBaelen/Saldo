# Version 0.7 · Planning

**After this version you can** see how each of the coming months ends for each account group, with the daily balance, the days you dip into the buffer or below zero, and how much is still free to spend. You confirm recurring items, set budgets and plan one-off expenses and incomes.

This answers the core question of the analysis: *"Will I have enough money at the end of each coming month, and how much is left or short?"*

Status: planned. Analysis milestone: M5. Roadmap: [../README.md](../README.md).

## Features
| Id | Feature |
|---|---|
| PLAN-1 | Recurring items detected from history and confirmed by you |
| PLAN-2 | Budgets per category, or the average of past months |
| PLAN-3 | Plan a one-off expense or income from the calendar |
| PLAN-4 | Forecast per group: months (3 to 24) and daily balance, buffer and red states |
| PLAN-5 | Free to spend per group and month |
| PLAN-6 | Planning screen with five tabs; forecast and warnings on Start |
