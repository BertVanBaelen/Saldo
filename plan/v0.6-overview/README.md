# Version 0.6 · Overview

**After this version you can** see what you earned, spent and saved per month, quarter or year, per category with its share and trend, and open the transactions behind any number. Start shows your real balance now and this month's spending.

Status: planned. Analysis milestone: M4. Roadmap: [../README.md](../README.md).

## Features
| Id | Feature |
|---|---|
| OVER-1 | Income, expenses and saved per month, quarter or year |
| OVER-2 | Category breakdown with share, trend and drill-down to transactions |
| OVER-3 | Start: Saldo nu, spending this month, accounts and contributions |
